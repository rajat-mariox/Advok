# Advok

Project structure modeled after the KEBU project.

- `admin-panel/` — React + Vite + TypeScript admin panel
- `advok_app/` — Flutter mobile app

## Setup

Admin panel (run inside `admin-panel/`):

```
npm create vite@latest . -- --template react-ts
npm install
```

Flutter app (run inside `advok_app/`):

```
flutter create .
```
